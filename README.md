# portas-logicas-arduino
Simulação no Tinkercad de portas lógicas (AND, OR, NOT e XOR) utilizando Arduino. O projeto demonstra o funcionamento das operações lógicas básicas por meio de entradas digitais e LEDs como saídas.

## 🧠 Descrição do Projeto
O circuito simula as operações lógicas básicas com **entradas digitais** e **LEDs** representando as **saídas**.  
Cada porta lógica foi implementada através de funções específicas no código (`portaAnd`, `portaOr`, `portaNot` e `portaXor`).
as portas recebem sinais de entrada com interruptores e retornam o resultado lógico conforme a tabela verdade de cada uma.

## 🧩 Componentes Utilizados
- 1 × Arduino Uno R3  
- 3 × LEDs  
- 3 × Resistores 220Ω
- 3 x Resistores 1 kΩ 
- 5 x interruptor Deslizante
